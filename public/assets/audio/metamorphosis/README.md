# Provisional room audio

`room.wav`, `outside.wav` and `voices.wav` are original, synthesized placeholders
for *La metamorfosis*. They contain no third-party samples or recordings.
Author/source: project-authored procedural synthesis, Codex-assisted; source
script: `src/story/metamorphosis/generate-audio.mjs`. License for these three
generated WAV files: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Run `node src/story/metamorphosis/generate-audio.mjs` to reproduce them.
The voices cue is an abstract murmur, not spoken dialogue. Replace the paths
in `src/story/metamorphosis/audio.ts` when final audio is ready.

# UI

Game UI belongs here.

Pixi'VN allows custom HTML/PixiJS interface layers. Build the project's organic illustrated UI here while keeping story data out of components.

Targets:
- portrait dialogue
- walk-and-talk overlays
- chapter cards
- inspection/evidence overlays
- pause/settings
- accessibility controls

UI state that must survive reloads should be represented in Pixi'VN storage rather than component-local state.

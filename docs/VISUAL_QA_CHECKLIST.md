# Visual QA Checklist

Use this before accepting any visual scene.

## Cohesion
- [ ] Character and background clearly belong to the same art style.
- [ ] Palette is controlled.
- [ ] Rendering/line treatment is consistent.
- [ ] No photorealistic asset has slipped into a stylized scene.

## Composition
- [ ] Clear focal point.
- [ ] Foreground / midground / background depth exists where appropriate.
- [ ] Character feels grounded in the environment.
- [ ] Character scale is believable relative to the room/world.
- [ ] UI does not cover essential story information.
- [ ] Scene does not look like a static slideshow by default.

## Narrative
- [ ] The composition matches the emotional beat.
- [ ] Important scene changes produce visual changes.
- [ ] Character pose/expression matches dialogue.
- [ ] Environment contains story information, not merely decoration.

## Responsive
- [ ] Checked at 1366x768.
- [ ] Checked at 800x600.
- [ ] No accidental crop.
- [ ] Text remains readable.
- [ ] Important props remain visible.

## AI-art rejection tests
Reject or revise if:
- [ ] face is hyperreal while world is stylized;
- [ ] costume has nonsensical detail;
- [ ] hands/anatomy are distracting;
- [ ] pseudo-text is visible;
- [ ] image feels like concept art rather than a production-ready game asset;
- [ ] subject is posed like a fashion/photo portrait instead of inhabiting the scene.

# Codex prompts

These are intentionally short because the repository already contains the project context.

## Start a new session

```text
Open this repository and follow AGENTS.md and docs/START_HERE.md. Continue the active execution plan for Heart of Darkness — The Journey. Work on the next unchecked task, validate your changes, and update the plan before finishing.
```

## Continue later

```text
Continúa con el plan activo. Haz la siguiente tarea pendiente, pruébala y actualiza el plan.
```

## Give Codex a specific feature

```text
Implementa [FEATURE]. Sigue AGENTS.md, reutiliza Pixi'VN cuando corresponda y no reconstruyas sistemas existentes. Integra el cambio con el plan activo y valida antes de terminar.
```

## Ask Codex to review what exists

```text
Revisa el estado actual contra el plan activo. No cambies código todavía. Dime qué ya funciona, qué falta y cuál debería ser la siguiente tarea concreta.
```

## Visual/gameplay polish pass

```text
Haz una pasada de calidad visual y de jugabilidad sobre la tarea actual. Mantén la arquitectura existente, corrige problemas visibles o de interacción, prueba en navegador y evita ampliar el alcance.
```

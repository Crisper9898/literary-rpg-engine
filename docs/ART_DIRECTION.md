# Art Direction

## Target
A stylized illustrated 2D RPG with a dark literary atmosphere, inspired by the production values of hand-drawn indie RPGs without copying any specific game's characters, UI or assets.

## Character standard
Each important character should have:
- concept sheet
- front / 3-4 / side reference
- consistent outfit and proportions
- idle and walk animations
- contextual interaction poses
- expressive dialogue portraits
- expression set: neutral, concerned, angry, surprised, tired, fearful, reflective

The map sprite and portrait must clearly read as the same person.

## Rendering language
Use:
- painterly or hand-drawn texture
- limited coherent palettes
- strong silhouettes
- layered shadows
- subtle irregularity
- depth through foreground / midground / background
- fog, smoke, rain, light masks and particles when scene-appropriate

Avoid:
- geometric placeholder characters in final production
- generic AI-looking faces
- mismatched illustration styles
- flat rectangular UI
- over-clean vector UI that feels detached from the world

## UI
Dialogue UI should support:
- portrait partially escaping the frame
- asymmetrical or organic frame silhouettes
- nine-slice decorative panels
- texture overlays
- speaker name hierarchy
- expression swaps
- minimal prompt icons
- responsive layouts for 1366x768 and larger

## Asset pipeline
Figma: interface and layout system.
Fal / image generation: concept art, variations, edits and asset production.
Manual review: consistency check before integration.

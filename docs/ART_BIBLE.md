# Literary RPG — Visual Bible

## 1. Design thesis
This project should look like a premium interactive literary graphic novel: authored, theatrical, moody and readable. The visual target is not realism. It is **cohesive stylization with narrative purpose**.

The player should be able to pause on almost any important scene and understand the emotional conflict from composition alone.

## 2. What currently works in La metamorfosis
Use the existing Metamorphosis presentation as a reference for:
- limited color palette;
- high contrast;
- bold silhouettes;
- graphic-novel character treatment;
- theatrical staging;
- red accents used sparingly;
- UI that feels integrated with the fiction;
- a character that visually belongs to the room and the story.

Do not copy exact assets across stories. Copy the **discipline**.

## 3. What to avoid
The biggest failure mode is stylistic incoherence: a realistic painted person placed over a stylized scene. Even if each image is individually attractive, the result looks cheaper because the viewer notices that the assets were made by different visual systems.

Other failure modes:
- too much detail everywhere;
- hyperreal human skin;
- characters centered like portrait photography;
- backgrounds with no staging zones;
- excessive HUD chrome;
- every scene using the same layout;
- character sprites that never change pose;
- dramatic moments using the same framing as exposition.

## 4. Shared visual grammar
### Shape
Use readable silhouettes and large forms before fine texture.

### Line
Prefer expressive ink-like or painted edges. Avoid ultra-clean vector characters unless the entire scene uses that language.

### Texture
Paper grain, brushed shadows, stained walls, fog, scratches and aged materials are welcome when story-relevant. They should not reduce readability.

### Light
Use motivated light sources: lamp, window, candle, lightning, furnace, moon, river glare. Light should help tell the story.

### Color
Limit each scene to a dominant family plus one accent. Reserve saturated accents for narrative importance.

## 5. UI language
- Literary serif for narrative where legibility remains strong.
- Small caps / restrained display typography for acts, chapters and metadata.
- One accent color per story.
- Thin rules, subtle paper/ink texture and intentional spacing.
- UI should frame the art, not overpower it.
- Dialogue box must feel like part of the book/game hybrid.

## 6. Scene variation toolkit
Use these to prevent visual monotony:
- full establishing background;
- close-up character crop;
- silhouette scene;
- foreground obstruction;
- lighting state swap;
- weather overlay;
- object insert / evidence card;
- letter/manuscript presentation;
- environmental animation;
- split composition for conflict;
- slow parallax where useful.

Do not use every technique at once.

## 7. Story palettes
### Metamorphosis
Black / ivory / brown / gray / red.
Expressionist interiors and psychological distortion.

### Frankenstein
Charcoal / midnight blue / cold cyan / bronze / amber.
Romantic landscapes + industrial/anatomical detail.
The laboratory should feel dangerous and sacred at the same time.

### Heart of Darkness
Black / parchment / moss / ochre / fog gray / ember.
Humidity, distance and uncertainty. The river should often dominate the composition.

## 8. Asset-generation rule
Any externally generated asset must be created from a written brief containing:
- story and scene;
- purpose in the composition;
- camera framing;
- lighting;
- palette;
- character pose/expression;
- style anchor;
- exact aspect ratio or transparent-background requirement;
- forbidden traits.

Do not generate from one-line prompts.

## 9. Quality target
The result should feel closer to a small indie studio with a strong art director than to a collection of individually generated images.
